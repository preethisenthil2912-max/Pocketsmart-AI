# Phase 8 – Project Demonstration

## Project Title

PocketSmart AI: Your Smart Budget & Recommendation Assistant

## Demonstration Steps

### Step 1 – Start the Application

Run the FastAPI application using Uvicorn.

### Step 2 – Open the Home Page

Display the PocketSmart AI home page.

### Step 3 – Create Account

Register a new user using name, email, and password.

### Step 4 – Login

Login using the registered credentials.

### Step 5 – Open Dashboard

The user should see the Smart Budget Planner.

### Step 6 – Enter Real-World Budget

Use the following example:

Monthly Income: ₹30000

Rent: ₹8000

Food: ₹5000

Transport: ₹2500

Utilities: ₹2000

Education: ₹2000

Healthcare: ₹1000

Entertainment: ₹1500

Other: ₹1000

Savings Goal: ₹5000

### Step 7 – Generate Budget Analysis

Click:

Analyze My Budget

### Step 8 – Display AI Recommendation

The application should display the budget analysis and recommendations.

### Step 9 – Show Database History

Return to the dashboard and show the previous budget entry.

### Step 10 – Demonstrate Health API

Open:

/api/health

### Step 11 – Demonstrate Gemini Status

Open:

/api/gemini-status

## Features Demonstrated

- User registration
- User login
- Budget input
- Budget calculation
- Gemini AI integration
- AI recommendations
- Savings recommendations
- SQLite database
- Previous budget history
- FastAPI API
- Health check
- Responsive interface
- Error handling

## Expected Result

The user enters realistic monthly budget information and receives a clear budget analysis and practical recommendations.

## Conclusion

The demonstration shows how PocketSmart AI combines Artificial Intelligence, FastAPI, SQLite, HTML, CSS, authentication, and API development into a practical budgeting application.
