## Project Overview

PocketSmart AI is an AI-powered web application that helps users analyze their monthly income and expenses and receive practical budget and savings recommendations.

The application uses FastAPI, Google Gemini AI, SQLite, HTML, CSS, and Jinja2.

## Main Features

- User registration
- User login
- Monthly budget input
- Expense analysis
- Savings goal
- Gemini AI recommendations
- SQLite database
- Budget history
- FastAPI APIs
- Health check
- Gemini status check
- Responsive web interface
